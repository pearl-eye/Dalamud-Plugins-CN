# Dalamud Plugins CN

## 简介

由 [pearl-eye](https://github.com/pearl-eye) 维护的国服卫月插件。

目前收录：

- [Allagan Tools CN](https://github.com/pearl-eye/InventoryTools)
- [Mortal MJ CN](https://github.com/pearl-eye/Mortal-MJ-CN)
- [Gathering Animation](https://github.com/pearl-eye/Gathering-Animation)
- [Gold Saucer Games](https://github.com/pearl-eye/Gold-Saucer-Games)

## 安装方式

在国服卫月设置的自定义插件仓库中添加并启用：

```text
https://raw.githubusercontent.com/pearl-eye/Dalamud-Plugins-CN/main/repo.json
```

## 反馈与贡献

仓库地址、插件列表或下载链接的问题，请提交到 [本仓库 Issues](https://github.com/pearl-eye/Dalamud-Plugins-CN/issues)。具体插件的翻译、界面和功能问题，请前往对应插件的源码仓库反馈，并提供插件版本、问题所在窗口和复现步骤。
